# 🚀 Day 1 — DevOps Basics

> Understanding DevOps, why it exists, and the role of a DevOps Engineer.

## What is DevOps?

**DevOps is a culture and approach focused on improving application delivery through automation, continuous testing, continuous monitoring, and collaboration.**

## Why DevOps?

### Before DevOps

Developer → Build Engineer → System Admin → QA → Release → Production

- Build Engineer → Builds the application
- System Admin → Creates/manages servers
- Release Engineer → Deploys the application
- QA → Tests the application

**Problem:** Multiple teams + handoffs + manual processes → **slow and inefficient delivery**

### After DevOps

Development → Automation → Build/Test → Deploy → Monitor → Production

**Result:** Faster, consistent, reliable and more efficient application delivery.

### Interview Point

> Before DevOps, application delivery involved multiple teams and a lot of manual work. DevOps brought better collaboration and automation, along with continuous testing and monitoring, to make application delivery faster and more efficient.

## 💡 Key Takeaway
